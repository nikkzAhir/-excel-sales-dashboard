# Sales Performance Dashboard in Excel

An interactive Excel dashboard that analyzes 2025 sales data across regions,
product categories, customer segments and sales representatives.

## Project Overview
This project turns raw sales data into a clear, filterable dashboard that
helps answer key business questions:
- How are sales and profit changing month by month?
- Which region, category and product perform best?
- Who are the top sales reps?
- Does offering higher discounts hurt profit?

## Dataset
- 240 orders from January to December 2025
- 4 regions, 12 cities, 4 categories, 13 products, 8 sales reps, 3 customer segments
- Columns: Order ID, Order Date, Region, City, Category, Product, Sales Rep,
  Segment, Quantity, Unit Price, Discount %, Sales, Profit Margin %, Profit

## Dashboard Components
| Component | Chart Type |
|---|---|
| KPI cards (Sales, Profit, Orders, Avg Order Value) | Cards |
| Monthly sales trend | Line chart |
| Sales by region | Column chart |
| Category share | Doughnut chart |
| Top 5 products | Bar chart |
| Sales vs profit margin by category | Combo chart |
| Region x category comparison | Stacked column |
| Sales rep leaderboard | Bar chart |
| Discount vs profit | Scatter plot |
| Segment contribution over time | Stacked area |
| Interactive filters | Slicers and Timeline |

## Tools Used
- Microsoft Excel (PivotTables, PivotCharts, Slicers, Timeline)
- Formulas: SUMIFS, COUNTA, TEXT
